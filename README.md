# 🚀 AegisAI

Production-grade Backend + GenAI project built with FastAPI, PostgreSQL, SQLAlchemy, Docker, and modern backend engineering practices.

---

## 📖 Project Overview

AegisAI is a production-style backend project designed to simulate how real engineering teams build scalable applications.

The project focuses on:

- Backend Engineering
- REST APIs
- PostgreSQL
- SQLAlchemy ORM
- Authentication
- Docker
- Testing
- GenAI Integration
- Production Architecture
